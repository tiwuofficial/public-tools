# Tier メーカー

- カテゴリ: 発想・ビジネスフレームワーク系候補
- 状態: 実装済
- 実装先: `src/tier-maker/index.html`

## 概要
S / A / B / C / D などの段位（tier）に項目を並べてランキングするツール（ティアリスト）。

## 要件メモ
- tier 行の追加・削除・名称・色のカスタマイズ
- 「未割当プール」から各 tier に項目をドラッグして配置
- 項目は文字（短い）。画像対応は任意
- 並び替え（同 tier 内の左右、tier 間の上下）
- localStorage 自動保存
- 画像（PNG）/ Markdown / JSON 出力
