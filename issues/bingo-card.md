# ビンゴカード生成

- カテゴリ: 遊び / 一般
- 状態: 実装済み

## 概要
パーティ・イベント・子供会で使えるビンゴ大会ツール。
標準的な 5×5（B-I-N-G-O、中央フリー）のビンゴカードを複数枚生成し、印刷できる。
あわせて番号抽選（数字コール）機能も備え、1台で大会を進行できる。

## 機能
- カードを指定枚数まとめて生成（各列は B:1-15 / I:16-30 / N:31-45 / G:46-60 / O:61-75）
- 中央マスを FREE にするか選択
- カードを印刷（window.print）
- 番号抽選: 1-75 から重複なくランダムに 1 つずつ引き、コール済みリストを表示
- 抽選のリセット
- 外部依存なし・単一 HTML 完結

## 対象ユーザ
子供〜大人。子供会・忘年会・結婚式二次会などの遊び用途。
