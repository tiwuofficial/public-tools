# 美容室 会計・終了時刻 計算

- カテゴリ: 仕事用 / 美容室
- 状態: 実装中(.wip)

## 概要
美容室の受付・会計向けツール。施術メニューを選ぶと合計金額・合計所要時間・終了予定時刻を
まとめて計算する。指名料・割引・税込/税抜の切替にも対応。

## 機能
- メニュー表（カット・カラー・パーマ等）を行で編集（名前・料金・所要分）。行の追加/削除、含める/含めないのチェック
- 開始時刻を入力 → 合計所要時間から終了予定時刻を算出（HH:MM）
- 指名料（円）の加算
- 割引（円 または ％）
- 料金が税抜のとき会計時に 10% を加算するトグル（既定は税込）
- 出力: 合計所要時間 / 終了予定時刻 / 小計・指名料・割引・税・合計金額
- 外部依存なし・単一 HTML 完結・日本語UI・PC専用

## 対象ユーザ
美容室・サロンの受付スタッフ。予約受付や会計時の素早い見積り・案内に。
