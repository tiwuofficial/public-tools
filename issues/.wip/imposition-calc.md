# 面付け計算（印刷）

- カテゴリ: 仕事用 / 印刷
- 状態: 未実装

## 概要
印刷会社・製版/DTP 向けの面付け計算ツール。原紙(全紙)サイズと仕上がりサイズから、
1 枚の原紙に何面取れるか（面付け数）を縦置き／横置きの両方向で試算して最大を採用し、
必要部数に対する必要原紙枚数と用紙利用率（ヤレ率の目安）を計算する。
レイアウトを SVG でプレビュー表示する。

## 機能
- 入力:
  - 原紙(全紙)サイズ: プリセット（菊全 636×939 / 四六全 788×1091 / A判全紙 625×880 / B判全紙 765×1085 / ハトロン判 900×1200）＋カスタム W×H(mm)
  - 仕上がりサイズ W×H(mm)
  - 用紙周囲の余白（くわえ等, mm）
  - ドブ（断裁しろ／面間ギャップ, mm）
  - 必要部数
- 出力:
  - 面付け数（面/枚）＝ 縦置き・横置きを比較した最大配置
  - 採用した向きと並び（列 × 行）
  - 必要原紙枚数 ＝ ceil(部数 ÷ 面付け数)
  - 用紙利用率(%) ＝ 仕上がり面積合計 ÷ 原紙面積
  - 面付けレイアウトの SVG プレビュー
- 外部依存なし・単一 HTML 完結・日本語UI・PC専用

## 対象ユーザ
印刷会社の営業／製版／DTP オペレーター。見積り時の用紙手配数の概算、面付け効率の比較に。

## 備考
- 単純な格子面付けのみ対応（変形・回転混在の最適面付けは対象外）。
- 端数・トンボ・くわえの厳密計算は行わず、見積り概算用途とする。
