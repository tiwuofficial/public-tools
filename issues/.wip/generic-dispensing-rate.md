# 後発医薬品調剤率 計算

- カテゴリ: 仕事用 / 薬局
- 状態: 実装中(.wip)

## 概要
調剤薬局向けの KPI 計算ツール。数量ベースの後発医薬品(ジェネリック)調剤率を計算し、
後発医薬品調剤体制加算の到達区分（加算1=80%/加算2=85%/加算3=90%）を判定する。
さらに「次の区分まであと何単位必要か」を逆算して表示する。

## 機能
- 入力: 後発医薬品の調剤数量 / 後発医薬品のある先発医薬品の調剤数量
- 出力: 数量ベースの調剤率(%)
  - 置換率 = 後発品数量 ÷ (後発品数量 + 後発品のある先発品数量) × 100
- 到達している体制加算区分を判定（80% / 85% / 90% のしきい値）
- 次区分到達に必要な「後発品への切り替え単位数」を逆算表示
- しきい値はUI上で確認できるよう明記
- 外部依存なし・単一 HTML 完結・日本語UI・PC専用

## 対象ユーザ
調剤薬局の薬剤師・事務。月次のジェネリック使用率の把握、体制加算の自己点検に。
