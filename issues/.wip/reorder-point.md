# 発注点・在庫日数 計算

- カテゴリ: 仕事用 / 酒販店・小売
- 状態: 実装中(.wip)

## 概要
在庫管理の基本指標を計算するツール。現在庫・平均日販・入荷リードタイム・安全在庫日数から、
在庫日数・発注点・在庫切れまでの日数を算出し、いま発注すべきかを判定する。
目標在庫日数を入れると推奨発注数も逆算する。酒販店など多 SKU の受発注・棚卸に。

## 機能
- 入力: 現在の在庫数(本) / 平均日販(本/日) / 入荷リードタイム(日) / 安全在庫(日数) / 目標在庫日数(日)
- 出力:
  - 在庫日数 = 在庫 ÷ 日販（あと何日もつか）
  - 発注点(本) = 日販 ×（リードタイム ＋ 安全在庫日数）
  - 在庫切れまでの日数（= 在庫日数の切り捨て）
  - 発注要否の判定（現在庫 ≤ 発注点 なら「発注タイミング」）
  - 推奨発注数(本) = max(0, ceil(目標在庫日数 × 日販 − 在庫))
- 0除算ガード（日販0 のときは在庫日数を「-」表示）
- 外部依存なし・単一 HTML 完結・日本語UI・PC専用

## 対象ユーザ
酒販店・小売の仕入れ／在庫担当。発注タイミングと発注量の素早い判断に。
