# おみくじ

- カテゴリ: 遊び / 一般
- 状態: 未実装

## 概要
ボタンを押すと運勢を引けるおみくじツール。お正月やちょっとした気分転換に。
大吉〜凶の運勢ランクを重み付きランダムで決め、項目ごとの一言や
ラッキーアイテムを表示する。

## 機能
- 「おみくじを引く」ボタンで運勢ランク（大吉/中吉/小吉/吉/末吉/凶）を抽選（重み付き）
- 願望・恋愛・仕事/学業・健康・金運・待ち人など項目ごとの一言
- ラッキーカラー / ラッキーナンバー / ラッキーアイテム
- もう一度引く
- 外部依存なし・単一 HTML 完結（メッセージはすべて内蔵）

## 対象ユーザ
子供〜大人。遊び・季節イベント・気分転換用。
