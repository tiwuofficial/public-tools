# 数取りカウンター

- カテゴリ: 一般 / 仕事・遊び
- 状態: 未実装

## 概要
ボタンを押すたびに数を数える数取りカウンター（タリーカウンター）。
イベントの入場者数、在庫の棚卸し、筋トレの回数、ゲームの得点など、
「数を数える」あらゆる場面で使える汎用ツール。

## 機能
- 複数のカウンターを作成・管理できる（ラベル付き）
- 各カウンターに +1 / -1 ボタンと大きな現在値表示
- 任意の加算ステップ（+5 など）の設定
- 各カウンターのリセット、削除
- 合計値の表示
- キーボード操作（選択中カウンターを Space / ↑ で +1、↓ で -1）
- localStorage で内容を保持（外部依存なし）

## 対象ユーザ
大人〜子供、仕事用（棚卸し・受付）から遊び用（ゲームの点数・回数数え）まで。
