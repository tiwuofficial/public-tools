# 記念日カウンター

## 概要

複数の記念日(誕生日・付き合った日・結婚記念日・推し活デビュー日 など)を登録すると、
今日までの日数や次の節目日を一覧表示するツール。

## 主な機能

- 記念日の登録(名前 + 日付)、複数件
- ブラウザに自動保存(localStorage)、外部送信なし
- 各記念日の表示: 経過日数 / 経過月 / 経過年 / 次の100日刻み(100,500,1000,...)までの残日数
- 結婚記念日の名称(銀婚式 25年 / 金婚式 50年 など)を該当年で表示
- 並び替え(次の節目が近い順 / 古い順)

## ターゲット

大人 / 遊び用。カップル・推し活・自分の人生記念日記録。
