# カラーコントラストチェッカー

- カテゴリ: 仕事 / デザイン
- 状態: 実装済み

## 概要
文字色と背景色のコントラスト比を計算し、WCAG（ウェブアクセシビリティ）の
基準を満たすか判定するツール。読みやすい配色か確認できる。

## 機能
- 文字色・背景色をカラーピッカー / HEX で入力
- コントラスト比（例 4.5:1）を計算
- WCAG 2.1 判定: 通常文字 AA(4.5:1)/AAA(7:1)、大きな文字 AA(3:1)/AAA(4.5:1)、UI部品(3:1)
- 合否をバッジで色分け表示
- サンプル文字（大・小）のライブプレビュー
- 文字色・背景色の入れ替えボタン
- 外部依存なし・単一 HTML 完結

## 対象ユーザ
大人。Web/資料デザイン、アクセシビリティ対応の配色チェックに。
