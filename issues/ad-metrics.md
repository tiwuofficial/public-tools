# 広告指標 計算（CPM / CPC / CTR / CVR / CPA / ROAS）

- カテゴリ: 仕事用 / 広告代理店
- 状態: 実装済み

## 概要
Web 広告運用の基本指標をまとめて算出する計算ツール。
インプレッション・クリック・コンバージョン・広告費・売上を入力すると、
CTR / CPC / CPM / CVR / CPA / ROAS / ROI を一括で計算してカード表示する。

## 機能
- 入力: インプレッション数 / クリック数 / コンバージョン数 / 広告費(円) / 売上(円, 任意)
- 出力指標:
  - CTR = クリック ÷ インプレッション × 100（%）
  - CPC = 広告費 ÷ クリック（円）
  - CPM = 広告費 ÷ インプレッション × 1000（円）
  - CVR = コンバージョン ÷ クリック × 100（%）
  - CPA = 広告費 ÷ コンバージョン（円）
  - ROAS = 売上 ÷ 広告費 × 100（%）
  - ROI = (売上 − 広告費) ÷ 広告費 × 100（%）
- 0除算は「-」表示でエラーにしない
- 外部依存なし・単一 HTML 完結・日本語UI・PC専用

## 対象ユーザ
広告代理店・インハウスの運用担当。レポート作成や提案前の素早い試算に。
