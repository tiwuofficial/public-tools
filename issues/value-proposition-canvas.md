# Value Proposition Canvas (バリュープロポジションキャンバス)

- カテゴリ: 発想・ビジネスフレームワーク系候補
- 状態: 未実装

## 概要
顧客プロフィール（仕事・痛み・利得）と価値マップ（製品・痛みの解消・利得の創出）を対にして、価値の適合（fit）を検討するフレーム。

## 要件メモ
- 顧客プロフィール: Customer Jobs / Pains / Gains
- 価値マップ: Products & Services / Pain Relievers / Gain Creators
- localStorage 自動保存
- Markdown / JSON 出力
