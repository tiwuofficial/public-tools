# 4 象限ジェネレータ

- カテゴリ: 発想・ビジネスフレームワーク系候補
- 状態: 実装済
- 実装先: `src/four-quadrant/index.html`

## 概要
2 軸（縦・横）で 4 象限に分類する図を作るツール。Eisenhower Matrix（重要 × 緊急）、Effort × Impact、メリット × デメリットなどに利用できる。

## 要件メモ
- 軸ラベル（上下左右）の編集
- 各象限にラベル / 説明
- 項目を追加して任意の象限に配置（ドラッグ移動可）
- localStorage 自動保存
- Markdown / JSON 出力, PNG 出力
