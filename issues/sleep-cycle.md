# 睡眠サイクル計算

- カテゴリ: 生活 / 一般
- 状態: 実装済み

## 概要
睡眠を約90分サイクルで区切り、すっきり起きやすいタイミングを提案するツール。
「起きたい時刻」から逆算して寝るべき時刻の候補を出す／
「今から（または指定時刻に）寝る」場合に起きるとよい時刻の候補を出す。

## 機能
- モードA: 起床時刻を入力 → 就寝時刻の候補（4〜6サイクル＝6/7.5/9時間など）を表示
- モードB: 就寝時刻（「今すぐ」ボタンあり）→ 起床時刻の候補を表示
- 入眠にかかる時間（デフォルト15分）を考慮
- 各候補にサイクル数と合計睡眠時間を併記
- 推奨サイクル（5〜6）をハイライト
- 外部依存なし・単一 HTML 完結

## 対象ユーザ
大人〜学生。生活リズムの調整・寝坊対策に。
