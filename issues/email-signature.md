# メール署名ジェネレータ

## 概要

氏名・会社・部署・役職・電話・メール・URL・住所などを入力すると、
ビジネスメールでよく使う署名（プレーンテキスト）を組み立てるツール。
区切り線のスタイルを選択できる。

## 主な機能

- 入力フィールド: 氏名 / かな / 会社名 / 部署 / 役職 / 電話 / Mobile / FAX / メール / URL / 住所
- 区切り線スタイル選択(=== / --- / ─── / ＝＝＝ / なし)
- レイアウトテンプレ選択(シンプル / 二重線 / 罫線)
- プレビュー(等幅) と コピーボタン
- 入力は localStorage に自動保存

## ターゲット

大人 / 仕事用。新人・転職時に署名を整えたい人。
