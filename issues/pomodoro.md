# ポモドーロタイマー

- カテゴリ: 仕事・勉強 / 一般
- 状態: 実装済み

## 概要
ポモドーロ・テクニック用のタイマー。一定時間の集中作業と短い休憩を
繰り返し、数セットごとに長い休憩を挟む。仕事や勉強の集中力維持に使う。

## 機能
- 作業時間・短い休憩・長い休憩・長い休憩までのセット数を設定（既定 25/5/15/4 分）
- 大きな mm:ss 表示と現在フェーズ（作業中／休憩中）の表示
- スタート / 一時停止 / リセット
- フェーズ終了でビープ音（Web Audio、外部依存なし）を鳴らし自動で次フェーズへ
- 完了した作業ポモドーロ数のカウント
- タブのタイトルに残り時間を表示
- 設定は localStorage に保持

## 対象ユーザ
大人（在宅勤務・社会人）から学生まで。仕事・勉強の集中管理に。
