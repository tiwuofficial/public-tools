# 施肥量計算（N-P-K）

## 状態

実装済み

## 概要

化成肥料の成分（N-P₂O₅-K₂O %）と圃場面積、目標窒素施肥量（kg/10a）から、
必要な肥料の量（kg）・袋数・同時に投入される各成分量を概算する、農業向けの実務ツール。

## 想定ユーザ

- 農家・営農指導員・家庭菜園の作付け計画

## 入力

- 圃場面積（a）※1a = 100m²、10a = 1反
- 化成肥料の成分 N / P₂O₅ / K₂O（%）デフォルト 8-8-8
- 目標窒素（N）施肥量（kg/10a）
- 1袋の重量（kg）デフォルト 20

## 出力

- 必要な肥料の総量（kg）
- 袋数（切り上げ）
- その肥料で同時に投入される N / P₂O₅ / K₂O 量（kg）

## メモ

- 外部依存なし・単一HTMLで完結。窒素基準で算出し、P・Kは結果として併記する方式。
