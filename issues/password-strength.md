# パスワード強度チェッカー

- カテゴリ: 仕事・生活 / セキュリティ
- 状態: 実装済み

## 概要
入力したパスワードの強度を推定エントロピー・解読時間・要件で評価するツール。
生成ではなく評価が目的（パスワード生成は別ツール）。入力はブラウザ内のみで処理。

## 機能
- パスワード入力（表示/非表示切替）
- 文字種から推定エントロピー(bit)と推定解読時間を算出
- 強度メーターと5段階評価（とても弱い〜とても強い）
- よくあるパスワードの検出
- 要件チェック（長さ・大小英字・数字・記号・同字連続・既知でない）
- 外部依存なし・単一 HTML 完結

## 対象ユーザ
大人。アカウントのパスワード見直し・セキュリティ意識向上に。
