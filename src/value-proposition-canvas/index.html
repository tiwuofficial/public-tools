Value Proposition Canvas

顧客プロフィール（仕事・痛み・利得）と価値マップ（製品・痛みの解消・利得の創出）を対にして、価値の適合 (fit) を検討します。

V

価値マップ (Value Map)

私たちが提供する側
P

Products & Services（製品・サービス）

価値を構成する具体的な提供物。機能・モジュール・サービスメニュー。

    PR

    Pain Relievers（痛みの解消）

    顧客の Pains を、どのように軽減・解消するか。

      GC

      Gain Creators（利得の創出）

      顧客の Gains を、どのように生み出し / 増幅するか。

        C

        顧客プロフィール (Customer Profile)

        受け取る顧客側
        CJ

        Customer Jobs（顧客の仕事）

        顧客が成し遂げたい機能的・社会的・感情的なジョブ。

          PA

          Pains（痛み・障害）

          ジョブを遂行する上での悩み・障害・リスク・避けたい結果。

            GA

            Gains（利得）

            期待・必要・望み・嬉しい驚きとなる成果。

              Markdown プレビュー

              

  
              
    左の「価値マップ」は私たちが作る側、右の「顧客プロフィール」は顧客側を表現します。Pain Relievers と Pains、Gain Creators と Gains が対応するように記述すると fit を検証しやすくなります。
