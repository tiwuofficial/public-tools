4P 分析

マーケティング・ミックスの定番フレーム。Product / Price / Place / Promotion の 4 観点で施策を整理します。

P¹Product（製品）

機能・品質 / デザイン / ブランド / パッケージ / 保証 / ラインナップ

    P²Price（価格）

    価格水準 / 値引き / 支払条件 / 割引 / サブスク・買い切り / 競合比較

      P³Place（流通・チャネル）

      販売経路 / 物流 / 在庫 / 出店地域 / オンライン / 直販 / 代理店

        P⁴Promotion（販促）

        広告 / PR / SNS / イベント / インフルエンサー / SEO / クチコミ

          Markdown プレビュー

          

  
          
    4P は売り手視点のフレームです。顧客視点で考える場合は 4C（Customer Value / Cost / Convenience / Communication）と対応付けて整理すると整合が取りやすくなります。
