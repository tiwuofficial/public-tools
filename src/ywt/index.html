YWT 振り返り

日本発の振り返りフレーム。やったこと (Y) / わかったこと (W) / 次にやること (T) の 3 列で行動と学びを整理します。

Yやったこと

期間中に実際に行ったアクション・取り組み（事実ベース）

    Wわかったこと

    やってみて気づいたこと・学び・うまくいった/いかなかった理由

      T次にやること

      学びを踏まえた次のアクション・改善点・新しく試したいこと

        Markdown プレビュー

        

  
        
    Y → W → T の流れで埋めるのが基本です。Y の「事実」と W の「解釈・学び」を切り分けると T の質が上がります。各項目はクリックで編集モードに切り替わります。
