public-tools

ブラウザだけで動く便利な web ツール集。

ツール一覧

  • 文字数カウンタ
    文字数・単語数・行数・バイト数をリアルタイム計測。
  • 差分比較
    2 つの文章を行単位で比較してハイライト表示。
  • タイマー / ストップウォッチ
    カウントダウンタイマーとラップ計測付きストップウォッチ。
  • ルーレット
    入力した項目から 1 つをランダムに抽選。
  • あみだくじ
    参加者と当たりを入力してランダムなあみだくじを引く。
  • カラーピッカー
    HEX / RGB / HSL を相互変換しコピー。
  • JSON 整形
    JSON の整形・圧縮・キーソートとシンタックスハイライト。
  • コード整形 (HTML / CSS / JS)
    HTML・CSS・JavaScript の簡易フォーマッタ（外部依存なし）。
  • Unix time 変換
    タイムスタンプと日時を相互変換、現在時刻も表示。
  • Base64 エンコード / デコード
    UTF-8 文字列と Base64 を相互変換、URL safe にも対応。
  • 正規表現テスター
    JavaScript の RegExp でマッチ確認・置換、ハイライト表示。
  • パスワード生成
    crypto.getRandomValues を使った安全な乱数でパスワードを生成。
  • UUID 生成
    UUID v4 (ランダム) と v7 (時刻ベース) を一括生成。
  • Markdown プレビュー
    Markdown をリアルタイムに HTML 変換、テーブル/タスクリスト対応。
  • QR コード生成
    テキストや URL から QR コードを生成（外部依存なし、PNG 保存可）。
  • URL エンコード / デコード
    パーセントエンコード変換とクエリ文字列のパース／組み立て。
  • ハッシュ計算
    テキスト/ファイルの SHA-1 / 256 / 384 / 512 を一括計算。
  • 画像加工
    リサイズ・JPEG/WebP 圧縮・グレースケール / セピア / 反転・明度/コントラスト調整。
  • 進数変換
    2 / 8 / 10 / 16 進相互変換と AND/OR/XOR/NOT/シフト演算。
  • 時間単位変換
    秒・分・時間・日を相互変換、HH:MM:SS や 1h30m 表記にも対応。
  • 電卓
    四則演算・%・メモリ・税込/税抜・履歴つきの電卓。キーボード対応。
  • 割り勘計算
    合計金額と人数から 1 人あたりを計算、幹事の上乗せ・端数丸め対応。
  • 年齢計算
    生年月日から満年齢・生まれてからの日数・干支・星座・次の誕生日まで。
  • 文字置換
    複数の置換ペアを一括適用。大文字小文字・正規表現・単語境界に対応。
  • 文字種変換
    大小・全半角・ひらカタ・命名規則・並べ替えなど 20+ の変換をワンクリック。
  • 単位換算
    長さ・重さ・温度・面積・体積・速度・データサイズの相互変換。
  • 日付計算
    2 日付の期間計算と日付の加減算。営業日（月〜金）モード対応。
  • BMI 計算
    身長・体重から BMI と肥満度判定、標準体重・美容体重を表示。
  • メモ帳
    複数ノート対応の自動保存メモ帳（ブラウザ内に保存、外部送信なし）。
  • 割合計算
    パーセントに関する 5 パターンの計算（割引・増減率・◯%は何 など）。
  • ダミー画像生成
    幅・高さ・色を指定してプレースホルダー画像を生成（PNG/JPEG/WebP/SVG）。
  • コイントス・サイコロ・じゃんけん
    迷ったときの抽選セット。複数サイコロや TRPG 用 d20 にも対応。
  • TODO リスト
    優先度・期限つきタスク管理。ブラウザに自動保存（外部送信なし）。
  • 西暦・和暦変換
    明治以降の元号と西暦を相互変換、干支・曜日・元号期間も表示。
  • 入学・卒業年計算
    生年月日から小中高大の入学年・卒業年を西暦＋和暦で表示（履歴書用）。
  • テーブルジェネレータ
    セルを編集して Markdown / HTML / CSV / TSV のテーブルを生成。CSV 取り込みも可。
  • CSS Box Shadow ジェネレータ
    スライダで影をリアルタイム編集、複数シャドウ重ね合わせ・プリセット付き。
  • IP アドレス確認
    グローバル IP・ブラウザ環境情報・ローカル IP (WebRTC) を表示。
  • CSS Gradient ジェネレータ
    線形・放射状・円錐グラデーションをスライダで作成、CSS をコピー。
  • HTML 閉じタグチェッカ
    HTML の閉じ忘れ・対応していない閉じタグ・余分な閉じタグを行番号つきで指摘。
  • OGP / メタタグ確認
    URL または HTML から OGP・Twitter Card を抽出し、シェア時の見た目をプレビュー。
  • Lorem Ipsum / ダミー文章 生成
    英文・日本語のダミー文章を段落／文／単語／文字単位で生成。
  • CSS Border Radius ジェネレータ
    4 隅 × X/Y を独立に編集、楕円対応＆プリセット (ブロブ・葉等) 付き。
  • 読了時間 / SEO 文字数チェッカ
    記事の読了時間と SEO 目標バー、長文検出・漢字比率も表示。
  • 目次 (TOC) ジェネレータ
    Markdown / HTML の見出しからリンク付き目次を生成（MD / HTML 出力）。
  • HTML 要素抽出
    記事 HTML から見出し・リンク・画像 alt を一覧化し SEO チェック、CSV 出力対応。
  • キーワード出現頻度
    単語・文字 N-gram の出現頻度と密度をランキング表示。SEO の偏り確認に。
  • 数字 ⇄ 漢数字 変換
    アラビア数字と漢数字（位取り・読み式・大字）の相互変換、文中一括も可。
  • 重複行・重複文 検出
    同じ言い回しが繰り返されていないかを検出。行・文・連続フレーズに対応。
  • 配色テーマジェネレータ
    ベース色から補色・類似・三角・四角・モノクロマティックの配色を生成、CSS/Tailwind 出力対応。
  • メタタグ / OGP ジェネレータ
    SEO・OGP・Twitter Card のメタタグ HTML を入力フォームから自動生成。
  • .gitignore ジェネレータ
    OS・エディタ・言語・FW を選択して .gitignore を組み立てる。
  • チップ計算
    合計金額・チップ率・人数からチップ額と 1 人あたりの支払額を計算。
  • 文字並べ替え
    行を昇順・降順・自然順・数値順・長さ順・反転・シャッフルで並べ替え。
  • 文字検索
    テキスト中のキーワードを複数色分けで検索、件数・行/列位置・ハイライト表示。
  • 箇条書きジェネレータ
    改行・句点・任意の区切りでテキストを分割し Markdown / HTML の箇条書きを生成。
  • 括弧・引用記号の統一
    引用符・括弧の種類を文中で統一。半角⇄全角や鉤括弧化、スマートクォートにも対応。
  • SWOT 分析
    強み / 弱み / 機会 / 脅威の 4 マスを埋める分析テンプレート。Markdown / JSON 出力対応。
  • 記事構成テンプレ
    PREP / SDS / 起承転結 / AIDA / PASONA / 5W1H に沿って記事を構成し Markdown 出力。
  • 記事の読みやすさ指標
    一文の平均/最長、漢字・ひらがな比率、読点バランス、長すぎる文を可視化。
  • コピペ率チェック
    2 文章の N-gram 共通率・Jaccard・文字単位カバー率を計算しハイライト表示。
  • ビジネスモデルキャンバス
    9 ブロックでビジネスモデルを俯瞰するテンプレート。Markdown / JSON 出力対応。
  • リーンキャンバス
    スタートアップ向け 9 ブロック構成。課題 / 解決策 / UVP / 主要指標 / 圧倒的優位性 など。
  • ブレインストーミング
    付箋を自由に追加・移動・色分けでアイデア整理。Markdown / JSON 出力対応。
  • OG 画像ジェネレータ
    タイトル・グラデ背景から OGP 用 1200×630 画像を Canvas で生成 (PNG / JPEG)。
  • テキスト統計
    単語・文末ランキング、文長ヒストグラム、URL/数字/メンションの自動抽出。
  • ダミーデータジェネレータ
    氏名 / メール / 住所 / 電話 / 日付などのダミーデータを CSV / JSON / SQL で生成。
  • ホワイトボード
    SVG ベースの自由描画キャンバス。ペン / 直線 / 矩形 / テキスト / 付箋を配置、PNG 保存対応。
  • CSS triangle ジェネレータ
    向き 8 方向・サイズ・色を指定して CSS の三角形 (border ハック) を生成。
  • CSS Flex / Grid ジェネレータ
    Flexbox / Grid の主要プロパティを指定し、CSS とプレビューを生成。
  • 4 象限ジェネレータ
    2 軸で 4 象限に分類する図を作成。アイゼンハワー / 効果×工数 などのプリセット付き。
  • Tier メーカー
    S / A / B / C ... の段位リスト。ドラッグ＆ドロップで項目をランキング、PNG 出力対応。
  • 意思決定マトリクス
    選択肢を重み付き評価軸で得点化、加重合計で比較。最高得点をハイライト。
  • KPT 振り返り
    Keep / Problem / Try の 3 列で振り返り。項目を列間で移動、Markdown / JSON 出力。
  • 共感マップ
    ペルソナの言うこと / 考え / 行動 / 感情 / 痛み / 得たいこと の 6 ブロック。
  • OKR テンプレート
    Objective + 3〜5 KR で目標を定義。現在値・目標値から達成率を自動計算、進捗バー付き。
  • Value Proposition Canvas
    価値マップ × 顧客プロフィールで価値の適合 (fit) を検討するキャンバス。
  • ペルソナシート
    ターゲット顧客像を 1 枚に。基本属性 / 価値観 / 目標 / 悩み / 利用シーンを整理。
  • 3C 分析
    Customer / Competitor / Company の 3 つの観点で事業環境を整理。Markdown 出力対応。
  • 4P 分析
    Product / Price / Place / Promotion のマーケティングミックスを 4 列で整理。
  • PEST 分析
    政治 / 経済 / 社会 / 技術のマクロ要因を整理。+/− の影響タグ付き。
  • YWT 振り返り
    やったこと / わかったこと / 次にやること の 3 列で行動と学びを整理。
  • Crontab ジェネレータ
    5 フィールドを GUI で組み立て、cron 式・意味・次回実行を表示。プリセット付き。
  • 会議コスト計算
    参加者数・時給(または年収)・時間・頻度から会議コストを算出。
  • 九九練習
    段を選んでランダム出題。タイムアタックで連続正解を狙う。
  • 数取りカウンター
    複数カウンターで数を集計。入場者数・棚卸し・回数・得点に。キーボード操作対応。
  • ガチャ確率計算
    排出確率と回数から「少なくとも 1 回当たる確率」、目標到達に必要な回数を算出。
  • 迷路ジェネレータ
    サイズ指定でランダムな迷路を生成。答え表示・PNG 保存も可。
  • ランダムグループ分け
    名前リストを班・チームへランダムに均等振り分け。班分け・チーム編成・組分けに。
  • メール署名ジェネレータ
    氏名・会社・連絡先を入力してビジネスメール用の署名を組み立て。コピー対応。
  • ビンゴカード生成
    5×5 ビンゴカードをまとめて生成・印刷。1〜75 の番号抽選機能つき。
  • 記念日カウンター
    複数の記念日を登録、経過日数と次の節目までの残日数を一覧表示。
  • 後発医薬品調剤率 計算
    調剤薬局向け。数量ベースのジェネリック調剤率と体制加算の到達区分・必要単位数を計算。
  • ポモドーロタイマー
    作業と休憩を繰り返す集中タイマー。時間設定・自動切替・ビープ・完了数カウント。
  • 時計の読み方練習
    アナログ時計をランダム表示して何時何分か答えるドリル。難易度切替対応。
  • 面付け計算（印刷）
    原紙と仕上がりサイズから面付け数・必要原紙枚数・用紙利用率を計算し、レイアウトをプレビュー。
  • 計算ドリル
    ＋−×÷ をランダム出題する暗算ドリル。難易度・問題数を選んでタイム＆正答率を記録。
  • 残業代計算
    時給/月給と残業時間から法定割増率を加味して残業代を算出。深夜/休日も対応。
  • 睡眠サイクル計算
    90分サイクルで、起床時刻から就寝時刻／就寝時刻から起床時刻のおすすめを提案。
  • コンクリート数量計算
    部位の寸法から生コン体積(m³)・ロス込み手配量・ミキサー車台数を概算。建設/土木の積算に。
  • 広告指標 計算
    Web 広告の CTR / CPC / CPM / CVR / CPA / ROAS / ROI をまとめて算出。運用レポート・試算に。
  • おみくじ
    ボタンで運勢を抽選。大吉〜凶＋項目別の一言・ラッキーアイテム表示。お正月や気分転換に。
  • 原価率計算
    メニュー売価と材料原価から原価率・粗利・粗利率を算出。目標原価率からの推奨売価も提示。
  • 施肥量計算（N-P-K）
    化成肥料の成分と圃場面積から、必要な肥料量・袋数・投入されるN/P/Kを概算。農業の施肥設計に。
  • 数当てゲーム
    指定範囲のランダム数を当てる。ヒントつき。最少クリア回数を記録。
  • 発注点・在庫日数 計算
    現在庫・日販・リードタイムから発注点と在庫日数を算出。発注タイミングと推奨発注数を判定。
  • 不動産投資 利回り計算
    物件価格・家賃・諸経費から表面利回り／実質利回り／NOI／投資回収年数を計算。
  • ローン返済計算
    借入額・年利・期間から毎月返済額・総返済額・利息を試算。元利均等／元金均等と年次予定表。
